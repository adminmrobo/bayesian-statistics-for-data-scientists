## 각 회차 페이지의 구조 (비전공자판)

표지 → 히어로 → **처음 오신 분께 — 이 페이지를 3줄로**(읽는 길 안내 · 접힌 내용 모두 펼치기) → 등장인물 → 왜 이 주제인가 → 큰 그림 → 칸 ①②③ → **한눈에 보는 대시보드** → 대결 → 정리 → 아웃트로 → 지식 색인 → 온톨로지·서지 꾸러미 → 바닥글.

칸마다(2026-11-11 초보자 읽기 개정): **이 칸에서 가져갈 한 가지**(한 줄 핵심) · **왜 이 방법을 쓰나**(문제 상황 → 앞 방법의 한계 → 해법 → 쉽게 말하면) · **수학 수식을 어려워하는 조수가 대신 물어봅니다**(학교 수학 단원 → 식 조각 표 → 숫자로 한 번 해 보기) · 일상으로 치면 | 통계로는 · 칸 대화 · 실험 패널 · 풀이와 이 칸의 한계 · (코드가 있는 칸만) 접어 둔 파이썬 코드 · 확인 퀴즈 2문항.

**동적 대시보드:** 1~13회차 페이지마다 그 회차의 핵심 모형을 한 화면에 모은 대시보드가 있습니다(슬라이더 · ▶ 재생 · 숫자 카드 4개 · 그림 2개 · 해석). 목차의 종합 대시보드에서는 회차 버튼으로 13개를 바꿔 가며 볼 수 있어요. 화면은 모두 흰 배경입니다.

## 데이터와 정확성

- 모든 실험·대결의 데이터는 **시드를 고정한 설명용 모형**이며 실제 데이터가 아닙니다. 그림마다 "예시값", "설명용 모형" 도장이 있습니다.
- 교안이 인용한 기업·플랫폼 수치 중 출처를 확인하지 못한 것은 쓰지 않거나 "교안 인용"으로 표시했습니다.
- 금융 회차(2·6·8)와 요약 페이지는 **교육용이며 투자 자문이 아닙니다.**
- 숫자는 모두 다시 계산했고, 원자료와 다른 곳은 각 페이지 바닥글의 **"원자료와 다르게 쓴 곳"**에 "원자료의 A를 이 페이지에서는 B로 바꿉니다"로 적었습니다. 주요 항목:

| 회차 | 원자료 | 이 시리즈 |
|---|---|---|
| 1·10 | 학습목표·학습내용이 다른 과정/회차 문구 | 본문 내용으로 바꿈 |
| 3 | 두 단어 스팸 확률 94.8% | 76.8% (나이브 베이즈 계산) |
| 4 | P(B>A) 98.7% | 99.1% (베타 분포 재계산), "신뢰구간" → "신용구간" |
| 6 | 대출 연체 확률 1.8%, 승인 | 2.5%, 기준 초과 → 추가 심사 |
| 6 | ρ = −0.5 두 자산 위험 "약 10%" | 7.5% |
| 7 | 날씨 정상분포 45·35·20% | 1/3씩 (이중확률행렬) |
| 7 | CLV 183,000원 | 141,900원 (전이 표를 밝혀 재계산) |
| 8 | 연 매출 평균 $1.6M | $1.83M |
| 9 | PPV(유병률 10%) 68.7% | 67.9% |
| 11 | "95% 신뢰구간 = 참값이 있을 확률 95%" | 빈도주의 신뢰구간과 베이지안 신용구간을 구분 |
| 5·6·7 | 문제풀기가 다른 회차 문항과 같음 | 회차 본문으로 새 문항 |
