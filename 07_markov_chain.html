왜 이 주제인가

상태가 흐른다

고객은 활성 → 휴면 → 이탈로, 날씨는 맑음 → 흐림 → 비로 옮겨 가요. 확률이 상태마다 다릅니다.

표 하나로 먼 미래까지

전이 표를 n번 곱하면 n단계 뒤의 분포가 나와요. 시작 상태를 몰라도 오래 지나면 같은 분포에 모입니다.

구글과 마케팅의 공통 언어

페이지랭크는 "무작위 서퍼가 오래 머무는 페이지", CLV는 "상태별 매출의 미래 합"이에요.

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

상태 정의 → 전이 표 → 거듭제곱 → 정상분포·가치.

① 상태 정의

맑음/흐림/비, 활성/휴면/이탈, 페이지 A~E

② 전이 표

각 줄의 합이 1인 확률표(데이터에서 셈)

③ 거듭 곱하기

오늘 분포 × P = 내일 분포, × Pⁿ = n일 뒤

④ 읽기

정상분포(장기 비율), 페이지랭크(중요도), CLV(미래 매출 합)

문제 상황

오늘 날씨(또는 고객 상태)를 알 때, 10일 뒤·100일 뒤의 확률을 알고 싶어요.

앞 방법의 한계

앞 회차들은 증거 하나로 믿음을 한 번 고치는 법이었어요. 상태가 시간을 따라 계속 옮겨 가는 흐름은 다루지 못해요.

해법

"맑음 다음 날은 맑음 70%, 비 30%"처럼 옮겨 갈 확률을 표로 만들어요(전이 행렬). 오늘 상태에 이 표를 날마다 다시 적용하면, 시작이 어땠든 결국 비율이 더는 바뀌지 않는 상태에 닿아요(정상분포).

쉽게 말하면 보드게임에서 지금 칸과 주사위만 알면 다음 칸의 확률을 알 수 있는 것과 같아요. 지나온 칸은 상관없어요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

표를 곱하고 또 곱하면 왜 결국 같은 숫자에 멈춰요? 교안은 45%·35%·20%라던데요?

학교 수학으로 보면 고등학교 「수학」의 행렬의 곱과 수열의 극한이에요.

내일 분포 = 오늘 분포 × P · n일 뒤 = 처음 × Pⁿ · 정상분포 π = π × P
P의 한 줄오늘 그 상태일 때 내일 각 상태로 갈 확률(합 = 1)
× P각 상태의 확률을 이동 확률대로 나눠 다시 모음
π = πP곱해도 변하지 않는 분포 = 들어오는 확률과 나가는 확률이 같아진 상태
숫자로 한 번 해 보기교안 표: 맑음(0.7, 0.2, 0.1), 흐림(0.3, 0.5, 0.2), 비(0, 0.3, 0.7)맑음에서 시작: 1일 뒤 맑음 70% → 2일 뒤 0.7×0.7 + 0.2×0.3 = 55%이 표는 열의 합도 모두 1(0.7+0.3+0 = 1 …)이라 정상분포가 1/3씩(33.3%)확인: (1/3, 1/3, 1/3) × P의 맑음 = (0.7 + 0.3 + 0) ÷ 3 = 1/3

곱해도 안 변하는 분포를 찾으면 되는군요. 이 표로는 45%·35%·20%가 아니라 셋 다 1/3이 나와요.

통계로는

마르코프 성질: 다음 상태의 확률이 현재 상태에만 달려 있어요. 전이 행렬의 각 줄은 합이 1이고, 거듭 곱하면 시작 상태와 무관한 정상분포로 수렴합니다(조건이 맞을 때). 게임에서 "지금 공격 중이면 다음도 공격 70%"는 1차 모형, 직전 행동까지 보면 2차 모형이에요.

실험 — 세 상태 날씨의 분포 변화

자세한 풀이 — 마르코프 체인의 세 가지 개념 (펼쳐 보기)
  1. 상태 전이 확률: 지금 상태에서 다음 상태로 갈 확률. 데이터로는 "i에서 j로 간 횟수 ÷ i에 있던 횟수"로 셉니다.
  2. 전이 행렬: 행 = 출발, 열 = 도착. 각 행의 합은 1이에요.
  3. 정상분포: 충분히 오래 지나면 시작과 상관없이 같은 비율로 안정돼요. π = πP를 풀거나 거듭제곱해 구합니다.
  4. 게임 적용: 교안은 레벨 15에서 이탈이 급증하는 패턴을 전이 확률로 찾아 난이도를 조정한 예를 들어요. 1차·2차 모형 비교는 같은 저자의 다른 해설 「플레이어의 다음 수」(markov_player)에서 더 자세히 다룹니다.

이 칸의 한계 · 정상분포는 "얼마나 자주 그 상태에 있나"를 알려 줄 뿐, 연결 구조 속에서 어떤 상태(페이지)가 더 중요한지는 따로 정의해야 해요.

이 칸에서 가져갈 한 가지

링크를 따라 아무렇게나 돌아다니는 사람이 오래 머무는 페이지가 중요한 페이지예요.

왜 이 방법을 쓰나

문제 상황

수많은 페이지 중 무엇이 중요한지 순위를 매겨야 해요. 링크를 많이 받은 페이지가 중요할까요?

앞 방법의 한계

링크 수만 세면 "누가 가리켰나"를 구분하지 못해요. 또 밖으로 나가는 링크가 없는 페이지에 들어가면 영원히 갇히는 문제가 생겨요.

해법

서퍼가 85%는 링크를 따라가고 15%는 아무 페이지로 순간이동한다고 정해요. 이렇게 오래 돌아다녔을 때 각 페이지에 머문 비율이 페이지랭크예요. 중요한 페이지가 가리키는 페이지일수록 점수가 커집니다.

쉽게 말하면 추천서는 많이 받는 것보다, 존경받는 사람에게 받는 것이 더 무게가 있어요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

링크를 3개 받은 페이지보다 2개 받은 페이지가 더 중요할 수 있어요?

학교 수학으로 보면 고등학교 「수학」의 연립방정식, 행렬과 반복 계산이에요.

PR(A) = (1 − d) ÷ N + d × Σ PR(T) ÷ C(T)
TA로 링크를 건 페이지들
C(T)T가 밖으로 건 링크 수. 링크를 많이 걸수록 하나하나의 무게는 작아짐
d링크를 따라갈 확률(0.85)
(1 − d) ÷ N순간이동으로 모든 페이지가 받는 기본 몫
숫자로 한 번 해 보기N = 5, d = 0.85 → 기본 몫 (1 − 0.85) ÷ 5 = 0.03"쇼핑"은 아무도 링크하지 않음 → PR = 0.03 (기본 몫만)"뉴스"는 링크 3개를 받지만 대부분 기본 몫뿐인 페이지에서 옴 → 약 0.26"시청"은 링크 2개지만 중요한 "카페"·"뉴스"에서 옴 → 약 0.45로 1위

링크 개수보다 "누가 가리켰나"가 중요하네요. 그래서 링크 수 1위와 페이지랭크 1위가 다를 수 있어요!

일상으로 치면

추천서 열 장보다 그 분야 권위자의 한 장이 더 무게가 있어요. 그 권위자가 추천서를 남발하지 않는다면 더욱 그렇죠.

통계로는

페이지랭크는 링크를 전이 확률로 바꾼 마르코프 체인의 정상분포예요. 중요한 페이지가 적은 링크로 가리킬수록 받는 쪽의 점수가 커집니다. 반복 계산 r ← d·M·r + (1−d)/N을 수렴할 때까지 되풀이해요.

실험 — 다섯 페이지의 링크와 중요도

자세한 풀이 — 페이지랭크 계산 순서 (펼쳐 보기)
  1. 링크 행렬: 페이지 i가 링크를 k개 걸었다면 각 링크로 갈 확률은 1/k.
  2. 감쇠 계수 d = 0.85: 85%는 링크를 따라가고, 15%는 아무 페이지로 순간이동해요. 링크가 없는 페이지에 갇히는 문제를 막습니다.
  3. 반복 계산: 모든 페이지에 같은 점수로 시작해 r ← d·M·r + (1−d)/N을 되풀이하면 수렴해요.
  4. 읽기: 수렴한 값이 무작위 서퍼가 각 페이지에 머무는 비율 = 중요도.

이 칸의 한계 · 페이지랭크는 "얼마나 자주 들르나"를 잴 뿐, 들른 상태가 돈을 얼마나 버는지는 담지 않아요. 고객의 상태에 매출을 붙이면 생애가치가 됩니다.

3고객 생애가치

활성·휴면·이탈 — 고객 생애가치(CLV)

방법: 고객 한 명의 미래 가치 계산(CLV)일상: 단골 고객의 앞으로 5년

고객의 상태를 활성·휴면·이탈 셋으로 나누고, 상태마다 기간당 매출을 붙여요. 전이 표를 거듭 곱해 앞으로의 기대 매출을 더하면 생애가치가 됩니다.

이 칸에서 가져갈 한 가지

고객이 다음 기에 남을지 떠날지를 확률로 이어 붙이면 고객 한 명의 미래 가치가 나와요.

왜 이 방법을 쓰나

문제 상황

마케팅 예산을 어떤 고객에게 쓸지 정하려면, 그 고객이 앞으로 벌어 줄 돈을 알아야 해요.

앞 방법의 한계

페이지랭크는 어디에 오래 머무는지만 세요. 상태마다 버는 돈이 다르다는 점, 먼 미래의 돈은 지금 돈보다 가치가 작다는 점은 담지 않아요.

해법

활성 고객 5만 원, 휴면 고객 1만 원처럼 상태마다 매출을 붙여요. 기간마다 "그 상태에 있을 확률 × 매출"을 구하고, 먼 기간일수록 깎아서(할인) 모두 더하면 생애가치가 나와요.

쉽게 말하면 적금 이자를 거꾸로 생각해 보세요. 5년 뒤의 5만 원은 지금의 5만 원보다 가치가 작아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

2기 기대 매출 37,000원은 어떻게 나와요? 그리고 왜 (1 + r)ᵗ로 나눠요?

학교 수학으로 보면 고등학교 「수학 I」의 등비수열과 그 합, 「수학」의 행렬의 곱이에요.

CLV = Σ (그 기의 상태 분포 · 상태별 매출) ÷ (1 + r)ᵗ, t = 0, 1, 2, …
상태 분포처음 [활성 1, 휴면 0, 이탈 0]에서 기마다 P를 곱한 값
상태별 매출활성 50,000원, 휴면 10,000원, 이탈 0원(교안 예시)
(1 + r)ᵗt기 뒤의 돈을 지금 가치로 바꾸는 할인. r = 10%
숫자로 한 번 해 보기1기(t = 0): 활성 100% → 50,000원2기(t = 1): 0.7×50,000 + 0.2×10,000 = 37,000원 → 현재 가치 33,636원3기(t = 2): 활성 55%, 휴면 24% → 29,900원 → 현재 가치 24,711원5기까지 더하면 CLV ≈ 141,900원 (이 페이지의 전이 표 기준)

이탈은 한 번 들어가면 나올 수 없는 "흡수 상태"라 시간이 갈수록 쌓이고, 할인까지 더해져 먼 미래 매출이 작아지는군요.

일상으로 치면

단골이 다음 달에도 올 확률, 1년 뒤에도 올 확률을 따져 보면, 지금 매출만으로는 그 손님의 값어치를 알 수 없어요.

통계로는

마르코프 CLV는 상태 전이 확률과 상태별 매출, 할인율로 미래 매출의 현재 가치를 계산해요. 교안은 활성→활성 0.75, 활성→휴면 0.15, 활성→이탈 0.10처럼 데이터에서 센 전이 확률을 예로 들고, 할인율은 보통 0.8~0.9(기간당 할인 계수)라고 설명합니다.

박사

활성 유지율을 70%에서 80%로 올리면 CLV가 얼마나 늘까요?

주판봇

10%p쯤이야. CLV도 10% 늘겠지.

초파리 연구원

조수(하루)

전이 표: 활성(0.7, 0.2, 0.1), 휴면(0.3, 0.5, 0.2), 이탈(0, 0, 1)로 정했어요.

실험 — 활성 고객의 기간별 기대 매출과 CLV

자세한 풀이 — 교안의 CLV 실무 4단계 (펼쳐 보기)
  1. 데이터 수집: 6개월~2년 이상의 거래 기록으로 고객 상태를 정의해요.
  2. 전이 확률 추정: P(i → j) = i에서 j로 옮겨 간 고객 수 ÷ i에 있던 고객 수.
  3. CLV 계산: 상태 분포 × 상태별 매출을 기마다 구하고 할인해 더해요.
  4. 세그먼트 활용: CLV가 낮은 고객에게는 이탈 방지, 높은 고객에게는 충성도 보상처럼 다르게 대응해요.

이 칸의 한계 · 전이 확률이 시간이 지나도 같다는 가정, 고객끼리 다른 성향(이질성), 시장 변화가 빠져 있어요. 확률이 불확실하거나 변수가 여럿 얽히면 공식보다 수천 번 굴려 보는 시뮬레이션(몬테카를로)이 필요합니다.
